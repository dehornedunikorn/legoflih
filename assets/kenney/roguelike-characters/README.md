# Kenney Roguelike Characters

License: CC0 1.0 Universal (public domain dedication)

This is the 918x203 transparent character spritesheet (16x16 cells with 1px spacing) and a small JSON atlas for the named sample frames. The pack contains modular adventurer character parts and equipment suitable for the game's top-down fantasy setting.

Important integration note:
- The sheet is a parts/spritesheet resource, not a set of animated character walk cycles.
- The atlas JSON only names a small subset of sample frames; the complete sheet is available for slicing/custom combinations.
- These files are added as source assets only. Existing gameplay sprite loading is not changed by this commit.
